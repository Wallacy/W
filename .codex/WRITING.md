# Escrita técnica controlada

> **Base:** ASD-STE100 Simplified Technical English, Issue 9, 15 de janeiro de
> 2025.

Este arquivo define a regra de escrita do repositório. O ASD-STE100 controla a
língua inglesa. As regras para português são uma adaptação local. Elas não são
uma tradução oficial do padrão.

## Escopo

Use estas regras nos seguintes conteúdos:

- documentação técnica e decisões de projeto
- planos, revisões e relatórios
- comentários de código e mensagens de commit
- textos de interface
- explicações e perguntas no chat
- raciocínio operacional que aparece em notas ou artefatos

Não altere código, símbolos, citações ou nomes técnicos para cumprir uma regra
de prosa. Preserve a precisão antes de reduzir o texto.

Melhore documentos antigos quando você alterar a seção correspondente. Não faça
uma reescrita global sem uma tarefa específica.

## Inglês

Use o ASD-STE100 Issue 9 em textos técnicos em inglês.

- Use o vocabulário aprovado e os termos técnicos do projeto.
- Use uma palavra com um significado estável.
- Use no máximo 20 palavras em uma instrução.
- Use no máximo 25 palavras em uma frase descritiva.
- Escreva uma instrução por frase.
- Use um tópico por parágrafo e no máximo seis frases por parágrafo.
- Use listas verticais para conteúdo complexo.
- Não use ponto e vírgula em prosa.

Consulte o padrão oficial quando uma regra lexical ou gramatical for importante.

## Português técnico controlado

Use estas regras como adaptação para português:

1. Use frases curtas, diretas e completas.
2. Dê uma função para cada frase: informar, exigir, recomendar ou perguntar.
3. Use uma instrução ou ação principal por frase.
4. Identifique o agente e a ação. Prefira a voz ativa.
5. Apresente a condição antes da ação quando a condição mudar o resultado.
6. Use um termo para cada conceito. Não troque sinônimos por variedade.
7. Defina siglas e termos novos na primeira ocorrência.
8. Use pronomes somente quando o referente for inequívoco.
9. Use listas para três ou mais itens relacionados ou para relações complexas.
10. Use um tópico por parágrafo. Use no máximo seis frases por parágrafo.
11. Evite o ponto e vírgula em prosa. Ele permanece válido em código e sintaxe.
12. Remova introduções vazias, elogios, metáforas e conclusões repetidas.

Use até 20 palavras em instruções quando a frase continuar natural. Não use mais
de 25 palavras. Use até 25 palavras em descrições quando possível. Não use mais
de 30 palavras. Divida a frase antes de distorcer a gramática.

Termos técnicos em inglês podem permanecer em inglês. Use a mesma grafia em todo
o projeto. Não misture uma tradução e o termo original sem uma necessidade real.

## Outros idiomas

Use um padrão técnico controlado do idioma quando ele existir. Registre esse
padrão antes de produzir um documento longo.

Se não existir um padrão adequado, use as regras semânticas deste arquivo. Ajuste
os limites de palavras para preservar a gramática natural. Não reduza a precisão
para cumprir uma contagem.

## Linguagem normativa

Use estes verbos com significado estável:

| Forma | Significado |
|---|---|
| `deve` / `must` | requisito obrigatório |
| `não deve` / `must not` | proibição |
| `recomenda-se` / `should` | recomendação com possível exceção |
| `pode` / `may` | permissão |
| `consegue` / `can` | capacidade comprovada |

Não use `deve` para fazer uma previsão. Use o futuro ou descreva a condição.
Não use `pode` quando o texto quer dizer somente que algo talvez ocorra.

## Chat, revisão e raciocínio

- Comece pelo resultado, decisão ou bloqueio.
- Não repita o pedido do usuário como introdução.
- Separe fato, inferência, proposta e decisão.
- Dê uma causa concreta para cada recomendação.
- Mostre alternativas em uma lista ou tabela curta.
- Faça perguntas independentes em itens separados.
- Não declare completude sem um critério verificável.
- Não repita a mesma conclusão no início e no fim.
- Use termos do projeto. Evite abstrações genéricas quando existe um nome exato.

O texto não deve parecer uma sequência de transições ou resumos automáticos.
Cada parágrafo deve acrescentar informação necessária.

## Verificação antes de concluir

Confirme estes pontos:

1. Cada frase tem uma função clara.
2. O sujeito e a ação estão identificáveis.
3. Cada termo mantém o mesmo significado.
4. Cada parágrafo contém um tópico.
5. Requisitos e propostas têm estados diferentes.
6. Listas paralelas usam a mesma estrutura gramatical.
7. O texto não repete contexto, justificativa ou conclusão.
8. Frases longas foram divididas sem perda de precisão.
