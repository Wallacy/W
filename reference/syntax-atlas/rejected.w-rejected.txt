W syntax atlas — Rejected witnesses

This file is not W source. The checker must not parse it.

- raw literals with arbitrary multiple hashes [W-218: rejected; W uses one fence]
- spawn on .compute let value = work()  [Retirado antes do 1.0]
- process.main = run                         [Rejeitado por enquanto]
- [value] as an object literal               [Rejeitado por enquanto]
- return await try operation()               [Rejeitado por enquanto]
- value as ? Ticket                          [Espaço separa `as` de `?`; rejeitado pela superfície]
- type of                                    [Subject ausente; rejeitado por W-PARSE-0020]
- reflect.TypeId.of<Ticket>()                [API legada; rejeitada sem compatibilidade]
- import reflect from std                    [Import legado; rejeitado sem compatibilidade]
- typeof value                               [Não adotado; rejeitado como superfície externa]
- plainValue is Ticket                       [W-TYPE-0130: source sem identidade dinâmica]
- value as? PartialTicket                    [W-TYPE-0124: target sem composição completa]
- return value as? Ticket                    [W-BORROW-0001: borrow escapa da origem]
- info of PlainTicket                        [W-TYPE-0128: sem Reflectable]
- TypeId.of<ReservationKey>()                [W-EXPR-0006: postfix core não fornecido]
- type(of: value)                            [superfície legada não fornecida]
- value as? Ticket as? OrderId               [W-TYPE-0124: resultado optional borrowed não é source válido]
- x |> f() ?? fallback                     [W-PIPE-0001: suffixo binary não parentetizado não é call template]
- x |> f() || fallback                     [W-PIPE-0001: suffixo lógico não parentetizado não é call template]
- type SortedResult<Element> = Array<Element> where isSorted(value) [WCCP0: use `T<(predicate)>`; no `where` carrier]
- type SortedResult<Element> = Array<Element><isSorted(value)>    [WCCP0: a value predicate needs the parenthesized contract envelope]
- type SortedResult<Element> = Array<Element> <(isSorted(value))>  [WCCP0: whitespace detaches the contract from its type head]
- type DefaultF8 = f8                                          [W-1651: f8 requires an explicit encoding such as f8<.e4m3fn>]
- type DefaultF6 = f6                                          [W-1651: f6 requires an explicit encoding such as f6<.e3m2fn>]
- type DefaultF4 = f4                                          [W-1651: f4 requires an explicit encoding such as f4<.e2m1fn>]
- build.w base profile `benchmark`                            [W-1533: only `debug` and `release` are base profiles; benchmark is an orthogonal recipe over a base profile]
- build.w base profiles `size`, `proof`, `distribution`, `sanitizer`, or `pgo` [W-1533: `size` is a defaults preset, proof an assurance policy, distribution an admission policy, and sanitizer/PGO instrumentation lanes]
- build.w profile `{ name: "release", debug: .sidecar }` [W-1533: debug sidecars are selected independently per output; they are not a required release-profile default]
- ELF `pie: true` on an `x86_64-pc-windows-msvc` target [W-1533: PIE/RELRO are ELF-specific; PE/Windows uses its target ASLR/DEP hardening contract]
- contract fn sameElements(before: Array<i64>, after: Array<i64>): Bool [WCCP0: `contract fn` is not an approved declaration kind]
- contract sorted(values: Array<i64>)                           [WCCP0: no dedicated top-level `contract` declaration]
- let proof: Proof<SortedResult<i64>>                            [WCCP0: public `Proof<C>` values are rejected]
- verify(values) / check(values)                                [WCCP0: runtime spellings remain open, not current syntax]
- /// note: contract: sameElements(input: values, output: result) [WCCP0: prose does not create a structured field]
- /// - contract: sameElements(input: values, output: result)      [WCCP0: list content is not a structured field]
- `/// contract: surfaceReady()` immediately before `module catalog` [WCCP0: module contracts belong in `module<contracts: [...]>`]
- module catalog<contracts: []>                                [WCCP0: the module contract list is nonempty]
- /// contract: sameElements(input: before values, output: result) [WCCP0: `before` is only an explicit mutable-state alias]
- /// contract: after values.count == result.count              [WCCP0: `after` requires `inout`, `mut ref`, or a mutable receiver]
- /// contract: newBalance == balance + amount                  [WCCP0: no compiler-created `newName` binder]

Contract-only ownership/property witnesses below are not checker evidence;
they state rejected contract shapes and intentionally provide no diagnostic IDs.

- `struct Bare { value: u16 }`                         [CONTRACT-ONLY: bare W field]
- `let value: mut ref u16 { get => storage }`          [CONTRACT-ONLY: computed let mut ref]
- `struct Stored { var value: inout u16 }`             [CONTRACT-ONLY: stored inout]
- `var text: inout String { get => label; set(value) { label = value } }` [CONTRACT-ONLY: computed inout String getter borrows label]
- `ref self` with a `mut willGet` read observer         [CONTRACT-ONLY: read mut observer through ref owner]
- readonly witness implemented with an extra `mut ref self` requirement [CONTRACT-ONLY: strengthened readonly witness]
- `edit(left: inout box.value, right: inout box.value)` [CONTRACT-ONLY: overlapping inout]
- `struct SharedPair: Copy { let owner: shared Node }`  [CONTRACT-ONLY: implicit Copy with shared owner]
