W syntax atlas — Rejected witnesses

This file is not W source. The checker must not parse it.

- raw literals with arbitrary multiple hashes [W-218: rejected; W uses one fence]
- spawn on .compute let value = work()  [Retirado antes do 1.0]
- process.main = run                         [Rejeitado por enquanto]
- [value] as an object literal               [Rejeitado por enquanto]
- return await try operation()               [Rejeitado por enquanto]
- value as ? Ticket                          [Espaço separa `as` de `?`; rejeitado pela superfície]
- type of                                    [Subject ausente; rejeitado por W-PARSE-0020]
- reflect.TypeId.of<Ticket>()                [API legada; rejeitada sem compatibilidade]
- import reflect from std                    [Import legado; rejeitado sem compatibilidade]
- typeof value                               [Não adotado; rejeitado como superfície externa]
- plainValue is Ticket                       [W-TYPE-0130: source sem identidade dinâmica]
- value as? PartialTicket                    [W-TYPE-0124: target sem composição completa]
- return value as? Ticket                    [W-BORROW-0001: borrow escapa da origem]
- info of PlainTicket                        [W-TYPE-0128: sem Reflectable]
- TypeId.of<ReservationKey>()                [W-EXPR-0006: postfix core não fornecido]
- type(of: value)                            [superfície legada não fornecida]
- value as? Ticket as? OrderId               [W-TYPE-0124: resultado optional borrowed não é source válido]
- x |> f() ?? fallback                     [W-PIPE-0001: suffixo binary não parentetizado não é call template]
- x |> f() || fallback                     [W-PIPE-0001: suffixo lógico não parentetizado não é call template]

Contract-only ownership/property witnesses below are not checker evidence;
they state rejected contract shapes and intentionally provide no diagnostic IDs.

- `struct Bare { value: u16 }`                         [CONTRACT-ONLY: bare W field]
- `let value: mut ref u16 { get => storage }`          [CONTRACT-ONLY: computed let mut ref]
- `struct Stored { var value: inout u16 }`             [CONTRACT-ONLY: stored inout]
- `var text: inout String { get => label; set(value) { label = value } }` [CONTRACT-ONLY: computed inout String getter borrows label]
- `ref self` with a `mut willGet` read observer         [CONTRACT-ONLY: read mut observer through ref owner]
- readonly witness implemented with an extra `mut ref self` requirement [CONTRACT-ONLY: strengthened readonly witness]
- `edit(left: inout box.value, right: inout box.value)` [CONTRACT-ONLY: overlapping inout]
- `struct SharedPair: Copy { let owner: shared Node }`  [CONTRACT-ONLY: implicit Copy with shared owner]
