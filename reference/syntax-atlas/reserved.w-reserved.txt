W syntax atlas — Reserved witnesses

This file is not W source. The checker must not parse it.

Reserved:
- `.bounded<budget:N>` is the W-1517 lexical allocator plan; this companion is
  not a W parser source file and does not provide a syntax witness.
- capture(...) is replaced by the contextual <[...]> capture prefix.
- named type arguments and binding modifiers are not grammar forms.
- URL, stdin, shebang, ambient cwd package discovery, ancestor scans, and
  recursive package discovery are not selected build-root forms. A `root`
  names one exact local path and may not be a glob, escaping path, or nested
  `build.w` file. A nested `build.w` is never discovered beneath a declared
  package root.
- `build { ... }` is local orchestration only. `package { ... }` records remain
  independently publishable; local root/resolution/deployment facts do not
  enter public package identity.
- The coordinator has no `include`, `extends`, or nested-root field. It cannot
  load another build configuration or form a configuration cycle.
- `w build <package>[:<product>]` is exact selection. `w build all` is an
  explicit aggregate request, never an implicit multi-package default.
- W compiler `--profile benchmark` and `--recipe ...` CLI spellings are not
  selected. Persist build configuration in `build.w`; benchmark is a recipe over
  `debug` or `release`, not a third base profile.
- The `size` preset is `build.w` configuration, not a base profile. Compiler
  `--size`, `--proof`, and `--distribution` CLI spellings are not selected.
- The seed's `--pie on|off` remains a temporary ELF control. It is not a
  permanent `build.w` spelling and is retired only after target-aware ELF PIE
  implementation, receipt binding, and focused native Windows ASLR/DEP and
  Linux/WSL ELF execution gates pass.
