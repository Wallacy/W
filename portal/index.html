01

Comece por aqui

Essenciais

Uma superfície familiar, tipada e pequena para as operações mais comuns.

Candidato

Bindings dizem quando mudam

const · let · var

Constante de compilação, valor imutável em runtime e variável mutável usam nomes distintos. 

const maxConnections: u16 = 128
let endpoint = URL("https://example.dev")
var attempts = 0

attempts += 1
const conhecido ao compilar let atribuído uma vez var mutação local
Candidato

Funções leem como contratos

fn

Parâmetros e retorno ficam juntos; inferência ajuda dentro do corpo.

fn clamp(value: i32, min: i32, max: i32): i32 {
  if value < min { return min }
  if value > max { return max }
  return value
}

let volume = clamp(value: 72, min: 0, max: 100)
Pesquisa

Transformações podem fluir

|>

Um operador de pipeline pode tornar cadeias lineares sem criar chamadas implícitas.

let label = input
  |> trim
  |> lowercase
  |> slug

// Deve equivaler a: slug(lowercase(trim(input)))
02

Modelar antes de executar

Tipos & modelos

Valor, identidade e variação são conceitos diferentes — e aparecem diferentes no código.

Candidato

struct é valor

value semantics

Dados compactos e independentes, comparáveis por conteúdo quando seus campos permitem.

struct Point {
  let x: f64
  let y: f64
}

let origin = Point(x: 0, y: 0)
let next = origin // outro valor
Candidato

object tem identidade

reference semantics

Entidades têm identidade e owner único; compartilhar exige um mecanismo explícito ainda em aberto.

object Session {
  let id: SessionId
  var state: SessionState
}

let primary = Session(id: id, state: .open)
let active = take primary // transfere o owner
Candidato

enum torna estados completos

sum type

Cada caso pode carregar dados; o consumidor trata todas as possibilidades.

enum LoadState<T> {
  idle
  loading(progress: f32)
  ready(T)
  failed(NetworkError)
}
switch state {
  case .idle: showPlaceholder()
  case .loading(let progress): show(progress)
  case .ready(let value): render(value)
  case .failed(let error): report(error)
}
Candidato

protocol descreve capacidade

contract

Comportamento é declarado sem impor hierarquia de objetos.

protocol Encodable {
  mut fn encode(self, to writer: inout Writer): Void throws EncodeError
}

fn persist<T: Encodable>(value: ref T): Void throws StoreError {
  // usa somente o contrato de T
}
Candidato

Ausência usa T?

.none

Nada de referência nula escondida: um valor opcional é presença ou .none.

fn nickname(for user: User): String? {
  if user.nickname.isEmpty { return .none }
  return user.nickname
}

if let name = nickname(for: user) {
  print(name)
}
Candidato

Restrições vivem no tipo

where

Tipos refinados podem validar fronteiras uma vez e carregar a garantia adiante.

type Port = u16 where value in 1...65535
type Percentage = f32 where value in 0...100

fn listen(on port: Port): Server throws BindError {
  // port já respeita o domínio declarado
}
03

Efeitos à vista

Fluxo & erros

Falhas recuperáveis fazem parte da assinatura e chamadas que podem falhar pedem try.

Candidato

O caminho de erro é tipado

throws · try

A assinatura anuncia falha; o ponto de chamada mostra propagação ou tratamento.

enum ConfigError: Error {
  missing(Path)
  invalid(line: u32, reason: String)
}

fn readConfig(at path: Path): Config throws ConfigError {
  // ...
}
fn boot(): App throws ConfigError {
  let config = try readConfig(at: "app.wconf")
  return App(config: config)
}

do {
  try boot().run()
} catch .invalid(let line, let reason) {
  eprint("linha ${line}: ${reason}")
}
Candidato

Padrões, sem cascata acidental

switch

Casos são exclusivos e podem decompor valores diretamente.

switch command {
  case .serve(let port) where port < 1024:
    requestPrivileges()
  case .serve(let port):
    try serve(on: port)
  case .version:
    print(build.version)
}
Candidato

Limpeza pertence ao escopo

defer

Recursos adquiridos localmente declaram sua liberação ao lado da aquisição.

fn inspect(path: Path): Header throws IoError {
  let file = try File.open(path)
  defer file.close()

  return try file.read(Header.self)
}

Duas intenções, duas palavras

Concorrência & paralelismo

async let organiza trabalho concorrente; spawn let pede execução paralela.

Candidato

async let

Sobrepor espera e I/O dentro de um escopo estruturado.

CONCORRÊNCIA
Candidato

spawn let

Distribuir trabalho computacional com isolamento verificável.

PARALELISMO
Candidato

Concorrência estruturada

async let · await

Filhos não escapam do escopo: conclusão, erro e cancelamento voltam ao pai.

async fn dashboard(for id: UserId): Dashboard throws ApiError {
  async let profile = fetchProfile(id)
  async let activity = fetchActivity(id)

  return Dashboard(
    profile: try await profile,
    activity: try await activity
  )
}
↳ O escopo aguarda ou cancela os dois filhos antes de sair.
Candidato

Paralelismo explícito

spawn let · await

O programador pede capacidade paralela; o sistema escolhe workers, não o resultado.

async fn sumBoth(values: [i64]): i64 {
  let middle = values.count / 2

  spawn let left = sum(values[..middle])
  spawn let right = sum(values[middle..])

  return await left + await right
}
↳ Capturas precisam ser seguras para cruzar uma fronteira paralela.
Em aberto

Políticas pertencem ao escopo

with timeout

Timeout, limite e cancelamento podem ser estruturais em vez de opções espalhadas.

with timeout(2.seconds) {
  async let primary = query(primaryStore)
  async let fallback = query(cache)
  return try await first(primary, fallback)
}

Em validação: forma da API, vencedor de first e regra de cancelamento dos demais filhos.

Ownership sem dominar a página

Memória & passagem

O caminho comum deve ser simples; operações que alteram ownership ganham vocabulário explícito.

ref Tempréstimo somente leitura
inout Tempréstimo mutável exclusivo
take valuetransfere ownership
copy valueduplica intencionalmente
Candidato

Custo excepcional fica visível

ref · inout · take · copy

Anotações aparecem nas fronteiras relevantes, não em cada uso cotidiano de um valor.

fn checksum(bytes: ref [u8]): u64
mut fn normalize(buffer: inout Buffer): Void
fn enqueue(job: take Job): Ticket
fn snapshot(state: ref State): State {
  return copy state
}
ref

Observa, não retém nem altera.

inout

Altera durante uma janela exclusiva.

take

Origem deixa de poder usar o valor.

copy

Custo de duplicação é solicitado.

Em aberto

Estratégia de memória

runtime?

ARC, regions, tracing seletivo e análise estática ainda precisam de protótipos comparáveis.

Invariante desejada

Sem use-after-free ou data race no código seguro; escape hatches isolados, auditáveis e explícitos.

07

Conviver com o mundo

Módulos & sistemas

Imports previsíveis e uma fronteira visível para código estrangeiro.

Candidato

Imports por nomes lógicos

import

A origem é legível e símbolos importados aparecem no cabeçalho do arquivo.

import { print, eprint } from std.io
import { Client, Response } from std.net.http
import { User, Session } from app.models
import std.crypto as hashes

let digest = hashes.digest(payload.bytes)
Candidato

FFI é uma fronteira nomeada

foreign c

ABI, tipos e operações inseguras ficam confinados a um bloco auditável.

foreign c from "stdlib.h" {
  fn malloc(size: c.size): c.ptr<Void>
}

fn allocate(size: c.size): Buffer? {
  let raw = malloc(size)
  if raw.isNull { return .none }
  return .some(Buffer(taking: raw, size: size))
}

O ponteiro C bruto pode ser nulo; a fronteira o verifica antes de produzir o wrapper opcional seguro.

Pesquisa

Uma ilha de outra linguagem

fn<C>

Código legado pode continuar dentro da aplicação enquanto uma boundary W tipada permite migração gradual.

fn<C> legacyTotal(_ items: c.ptr<Item>, _ count: c.size): c.double {
  return calculate_total(items, count);
}

let total = legacyTotal(items.raw, items.count)

Alternativas preservadas: source da aplicação com from, namespace C::unit e adapter declarado. Backend comum não elimina contratos de ABI, runtime e ownership.

Manifesto pequeno; resolução aninhada

package.w · resolution

A versão expressa intenção; a resolution aninhada registra fonte, conteúdo e resultado exatos.

package.w

package {
  schema: "w.package/1"
  name: "acme/aurora"
  version: "0.1.0"
  products: [{
    name: "aurora"
    kind: .executable
    root: "src/main.w"
  }]
  dependencies: [{
    alias: "http"
    package: "w/http"
    version: "^2.3"
    source: {
      kind: .registry
      registry: "w"
    }
  }]
}

resolution · visão resumida

{
  schema: "w.resolution/1"
  packages: [{
    alias: "http"
    package: "w/http"
    version: "2.3.1"
    sourceDigest: "<algorithm>:<hex>"
    target: "linux-x86_64"
  }]
}

Em aberto: formato final de resolution/attestations, algoritmo e migração de digest, identidade/namespaces e regras exatas de revogação/offline. Mirrors não confiáveis, provenance e publicação híbrida de source/artefatos já são a direção.

Candidato

O binário mantém sua proveniência

content-addressed

Bibliotecas verificáveis e metadados incorporados podem facilitar auditoria e identificação no produto final.

  • hash por conteúdo, não só por nome e versão
  • build reproduzível como requisito verificável
  • inventário exportável de componentes
  • mirrors com confiança e saúde observáveis

10

Escolhas que merecem protótipos

Alternativas em aberto

Não fechar cedo demais também é uma decisão de projeto.

Memória

Qual é o caminho comum?

ARC otimizado, regions/arenas, análise de ownership ou composição seletiva.

Medir latência, previsibilidade e carga cognitiva.
Execução

Quem hospeda o executor?

Runtime W pequeno, executor injetável, integração com event loops ou múltiplos perfis.

Separar a semântica da política.
Distribuição

Fonte, artefato ou ambos?

Pacotes source-first, binários verificados por target ou publicação híbrida.

Preservar auditabilidade e reprodutibilidade.
Compilação

Como implementar o core MLIR e o subset EmitC?

MLIR é a baseline; implementação do core e cobertura do backend EmitC continuam em aberto.

Prototipar o menor corte vertical.
Tipos

Como especializar genéricos?

Monomorfização, witness tables ou estratégia híbrida conforme fronteira ABI.

Tamanho, velocidade e incrementalidade importam.
W-039 · Execução

Como escolher um domínio sem prometer uma thread?

Isolamento serial, preferência de executor, afinidade e task group são contratos diferentes.

O líder usa async/spawn on; descriptors e forma angular continuam alternativas.
W-049/050 · Hosts

Como ligar handlers comuns a entradas do ambiente?

Slots versionados para processo, HTTP, UI e devices sem nomes mágicos ou contexto universal.

O líder usa entry; conformance e manifest-only continuam alternativas.
W-064–067 · Tensor/ML

O que precisa acompanhar a notação de matriz?

Shape, dtype, alias/view, broadcast, device, reductions e interoperabilidade observáveis.

Nested arrays e @ lideram; o açúcar não pode esconder cópias ou transfers.
W-014/015 · Tipos

O que realmente significa Type<...>?

Parâmetros declarados, refinements, identidade nominal e storage permanecem conceitos separados.

Refinement e parâmetros const declarados evitam um modifier map ad hoc.
Interop

Quão estreita é a fronteira C bruta?

Quais wrappers e capabilities restabelecem garantias ao voltar ao código seguro.

O local inseguro precisa ser encontrável.
