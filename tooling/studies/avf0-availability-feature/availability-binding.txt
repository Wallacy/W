if let acquire = available(CameraFrame.acquire) {
  let frame = acquire()

The binding must preserve the symbol's callable type, ownership, effects, and
capability requirements. Only compiler/provider evidence may create it. A
Boolean, OS version string, feature flag, or deployment field is not authority.
