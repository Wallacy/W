# AEG0 — App Essentials Gate

AEG0 closes five application boundaries. It records current design-oracle
evidence only. It does not claim W compiler, runtime, provider, FFI, or
deployment implementation.

The current witness covers nominal capabilities, separate civil values,
secure and deterministic random profiles, explicit codec/compression limits,
and scoped secret lifecycle. Crypto has separate revoke/rotation and expiry
paths; only deterministic seed/profile facts may enter a test receipt, while
secure seed/draw/bytes remain non-portable. The adversarial witness covers ambient lookup,
civil-clock deadlines, secure seeding and fallback, codec inference, and
plaintext or downgrade routes. `candidate.txt` is reserved text and is not
parsed as W.

The machine derives every route from facts. It rejects `expected`, `result`,
caller-owned status, stale source or digest, and implementation claims. The
bundle keeps compile, run, compiler, runtime, provider, FFI, stress, fault,
and human/model study evidence missing.
